# Güzellik Salonu

Güzellik salonu için tek sayfalık, telefona uyumlu web sitesi. Ek kurulum gerektirmez (HTML + CSS + JS).

## Bölümler

- Giriş (slogan ve "Randevu Al" düğmesi)
- Hizmetler ve fiyatlar
- Hakkımızda
- Online randevu formu (talep WhatsApp mesajı olarak gelir; Pazar kapalı, geçmiş saatler seçilemez)
- İletişim, çalışma saatleri ve harita
- Sağ altta sabit WhatsApp düğmesi

## Bilgileri değiştirme

- **WhatsApp numarası, hizmetler, fiyatlar, çalışma saatleri:** `script.js` dosyasının en üstündeki `AYARLAR` bölümü
- **Salon adı, metinler, adres, telefon, Instagram, harita konumu:** `index.html`
- **Renkler:** `style.css` dosyasının en üstündeki `:root` bölümü

## Görüntüleme

`index.html` dosyasını tarayıcıda açmanız yeterli. Yayınlamak için GitHub Pages kullanılabilir
(Settings → Pages → dal ve kök klasör seçilir).
